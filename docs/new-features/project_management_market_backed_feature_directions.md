# Market-Backed Feature Directions for SIPM

Date: 2026-03-14
Status: Proposed

This is a condensed feature-direction list based on the March 14, 2026 project-management market research and the current SIPM product target.

## Recommended Features

### 1. Initiative and Goals Layer

Add an initiative or objective layer above projects so leaders can track strategic outcomes, owners, target dates, and progress across multiple projects and solutions.

### 2. Portfolio Review Workspace

Create a dedicated executive portfolio view with health rollups, trend changes, bottlenecks, and summary-ready reporting for leadership review meetings.

### 3. Dependency and Critical Path Mapping

Add dependencies between projects, solutions, milestones, phases, and subcomponents so SIPM can show blockers, likely slip impact, and critical-path work.

### 4. Intake, Triage, and Approval Flows

Add structured request intake for new work, changes, and risks, then route those submissions through triage and lightweight approval paths before they become active records.

### 5. Capacity Scenarios and Planning Baselines

Allow planning windows to support multiple scenarios and baseline comparisons so teams can evaluate staffing or priority changes before committing them.

### 6. Rules and Alerts Engine

Add opinionated no-code automations for reminders, stale-item nudges, blocked-work escalation, approval notifications, and simple workflow follow-up actions.

### 7. Native Docs and Decision Logs

Add lightweight project and solution documents for briefs, meeting notes, decisions, assumptions, and closure summaries so execution context stays inside SIPM.

### 8. Template Packs

Provide reusable templates for common work types such as executive initiatives, engineering delivery, operational improvements, and audit or control efforts.

### 9. My Work / Inbox Experience

Add a personal action view that brings together assigned work, upcoming deadlines, pending approvals, stale items, and priority follow-ups for leaders and delegates.

### 10. Integrations and Event Sync

Expand connected workflow support with calendar sync, Slack or Teams notifications, email-to-intake, and lightweight GitHub or delivery-system signal pull-through.

## Notes

- These are medium-to-large feature candidates, not small polish items.
- The goal is to improve market fit without pushing SIPM toward heavyweight Jira-style complexity.
